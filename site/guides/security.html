Operate responsibly

Security & permissions

Desktop automation is powerful. Treat an agent with desktop access like a process that can use your keyboard, mouse, and visible applications.

Keep the server local

  • The HTTP endpoint binds to 127.0.0.1 by default.
  • Do not bind to 0.0.0.0 or expose the unauthenticated endpoint directly to the internet.
  • Use stdio when your MCP client can launch the process locally.
  • Connect only MCP clients and agents you trust.

Review agent actions

  • Be careful when the agent interacts with accounts, files, payments, or administrative interfaces.
  • Use supported application launching rather than arbitrary shell execution.
  • Do not grant elevated privileges just to make a desktop action work.
  • Keep the operating system and desktop environment updated.

Platform permissions

On macOS, the terminal or agent host may need Accessibility and Screen Recording permissions. On Linux, desktop actions depend on the logged-in graphical session and required system tools. Windows actions must run in the interactive user session rather than a Session 0 service.

Report a security issue

Please avoid publishing exploit details or private logs in a public issue. Contact the repository maintainer through the project's GitHub profile or repository channels and share only the information needed to reproduce the problem safely.

This documentation describes the project's current local-first design. It is not a security audit or a guarantee that every host configuration is safe.
