What can your agent do?

👀 See the screen

Capture a desktop screenshot and use it as visual context for the next action.

🖱️ Control input

Move and click the mouse, type text, and send keyboard shortcuts.

🪟 Manage windows

List, focus, switch, minimize, maximize, restore, and close windows.

🚀 Launch apps

Open supported desktop applications through native platform integrations.

Built for local control

The MCP server is designed to run on the computer being controlled. Its HTTP mode binds to loopback by default; it is not intended to be exposed directly to the public internet.
